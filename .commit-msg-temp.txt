Implement comprehensive Website Analytics dashboard with GA4 integration

- Enhanced google-analytics-query Edge Function to support multiple query types:
  * Summary metrics (sessions, users, pageviews, bounce rate, engagement)
  * Top pages with dimensions (pagePath, pageTitle)
  * Traffic acquisition (source, medium, conversion metrics)
  * Time series data for trend visualizations
  * Landing pages analysis

- Created useWebsiteAnalytics.ts hook with specialized query functions:
  * useWebsiteTraffic() - detailed traffic metrics
  * useTopPages() - ranked pages by views
  * useTrafficSources() - acquisition breakdown
  * useTrafficTimeSeries() - trend data for charts
  * useLandingPages() - entry page analytics

- Built reusable chart components in src/components/analytics/:
  * TrafficTrendChart - line/area charts for sessions over time
  * TopPagesChart - horizontal bar chart for top performing pages
  * TrafficSourceChart - pie chart for traffic distribution
  * AcquisitionTable - sortable data table with engagement metrics

- Created WebsiteAnalytics.tsx page with modern F-pattern layout:
  * Hero metrics section with north star metric (sessions) prominently displayed
  * Supporting metrics: users, pageviews, duration, bounce rate, engagement
  * Period selector (week/month/quarter/year)
  * Interactive trend charts with comparison mode
  * Top pages and traffic source visualizations
  * Comprehensive acquisition table with sorting
  * Responsive design with loading states and empty states

- Enhanced MarketingKPIs.tsx page:
  * Expanded GA4 metrics display (sessions, users, pageviews, duration)
  * Prominent "View Full Website Analytics" button linking to dedicated page
  * Conditional rendering based on GA4 authorization status
  * Improved user experience with clear connection status

- Updated navigation and routing:
  * Added "Website" to KPIs navigation menu with Globe icon
  * Created /kpis/website route in App.tsx
  * Integrated with existing authentication and layout system

All features tested and ready for production deployment.
